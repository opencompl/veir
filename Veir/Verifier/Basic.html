    Verifier #

    This file contains a collection of utilities for building program verifiers. A verifier is a function that checks invariants of programs that go beyond the basic well-formedness checks of the IR. For instance, checking that the operands of a binary add have the same type, or that a branch instruction forwards the correct number of operands to its successor blocks.

    def Veir.Attribute.branchArgCompatible (opTy argTy : Attribute) :
    Bool

    Type compatibility for values forwarded to block arguments or returned from functions. Register types are compatible when their register constraints agree, treating an unconstrained !riscv.reg (no index) as matching any physical register such as !riscv.reg<x0>. All other types must be equal.

    Equations
    • (Veir.Attribute.registerType r1).branchArgCompatible (Veir.Attribute.registerType r2) = (decide (r1.index = r2.index) || r1.index.isNone || r2.index.isNone)
    • opTy.branchArgCompatible argTy = decide (opTy = argTy)

        def Veir.OperationPtr.verifyBranchSuccessorArgTypes {OpInfo : Type} [HasOpInfo OpInfo] (op : OperationPtr) (ctx : WfIRContext OpInfo) (operandBase : Nat) (dest : BlockPtr) (errPrefix : String) :
        Except String PUnit

        Check that the operands forwarded to a successor block match the types of that block's arguments. operandBase is the index of the first forwarded operand; the forwarded operands are operandBase .. operandBase + dest.numArguments, mapped positionally onto dest's arguments. Callers must have already verified that this operand range is in bounds (i.e. the relevant segment size equals the successor's argument count).
