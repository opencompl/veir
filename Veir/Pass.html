      structure Veir.Pass (OpInfo : Type) [HasOpInfo OpInfo] :
      Type

      A compilation pass.

      • name : String

        Human-readable unique identifier for the pass, used for registration and pipeline configuration.

      • description : String

        Brief explanation of what the pass does, for documentation and tooling.

      • options : Std.HashMap String String

        The boolean options this pass accepts, mapping each option name to its help text. An option that the pipeline string does not name is false.

      • run : PassOptions → (ctx : WfIRContext OpInfo) → (op : OperationPtr) → op.InBounds ctx.raw → ExceptT String IO (WfIRContext OpInfo)

        Execute the pass over the given IR context rooted at op, under the options this instance of the pass was given. Returns the context on success, or an error message on failure.

              def Veir.PassPipeline.ofString? {OpInfo : Type} [HasOpInfo OpInfo] (registry : Std.HashMap String (Pass OpInfo)) (s : String) :
              Except String (PassPipeline OpInfo)

              Parse a comma-separated list of pipeline elements into a PassPipeline, looking each name up in registry. An element is either name or name{flag1 flag2 ...}, where the flags are boolean options accepted by that pass. Returns an error if a name does not exist in the registry, or if an element requests an option the pass does not accept.
