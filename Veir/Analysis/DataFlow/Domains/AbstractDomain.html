    Abstract Domain #

    A collection of order theoretic typeclasses used to define the AbstractDomain interface. The dataflow analysis framework uses this interface to describe abstract values, their lattice structure, and the concretization map that explains which concrete values an abstract value denotes.

                              class Veir.AbstractDomain (AbstractValue ConcreteValue : Type) [LE AbstractValue] extends Veir.JoinSemilattice AbstractValue, Veir.BoundedOrder AbstractValue :
                              Type

                              An abstract domain is a bounded join semilattice equipped with a concretization map.

                              Each abstract value denotes a set of concrete values via concretization.

                              • le_refl (a : AbstractValue) : a ≤ a
                              • le_trans (a b c : AbstractValue) : a ≤ b → b ≤ c → a ≤ c
                              • le_antisymm (a b : AbstractValue) : a ≤ b → b ≤ a → a = b
                              • join : AbstractValue → AbstractValue → AbstractValue
                              • le_join_left (a b : AbstractValue) : a ≤ a ⊔ b
                              • le_join_right (a b : AbstractValue) : b ≤ a ⊔ b
                              • join_le (a b c : AbstractValue) : a ≤ c → b ≤ c → a ⊔ b ≤ c
                              • top : AbstractValue
                              • le_top (a : AbstractValue) : a ≤ ⊤
                              • bot : AbstractValue
                              • bot_le (a : AbstractValue) : ⊥ ≤ a
                              • γ : AbstractValue → Set ConcreteValue

                                Concretization. Given an abstract value, returns the set of concrete values it denotes.

                              • γ_top : γ ⊤ = ⊤

                                The top element denotes every concrete value.

                              • γ_bot : γ ⊥ = ⊥

                                The bottom element denotes no concrete values.

                              • γ_monotone (a b : AbstractValue) : a ≤ b → γ a ⊆ γ b

                                The order is monotone (it is sound).
