    @[simp_getset] attribute and simp_getset tactics #

    This module defines the simp_getset and simp_getset? tactics, which try to apply all @[simp_getset]-tagged theorems. Unconditional theorems are used as ordinary simp rules. For theorems whose only explicit argument is an equality of the form f ... = ..., the tactic looks for hypotheses matching this shape and applies the theorems with these hypotheses as arguments.
