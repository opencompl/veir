    Correctness proofs for the nontrivial lowering patterns in ArithToLLVM.lean.

    These proofs are specialized to i8 so that veir_bv_decide can discharge them. The left-hand side states the source operation's value semantics, and the right-hand side is the expression computed by the sequence of LLVM operations emitted by the corresponding rewrite. Division inputs for which the source operation has undefined behavior are explicit disjuncts.

    source
    theorem Veir.Data.LLVM.Int.ceildivui_lowering (a b : BitVec 8) :
    b = 0 ∨ val (if a = 0 then 0 else (a - 1).udiv b + 1) = have zero := constant 8 0; have one := constant 8 1; have isZero := (val a).icmp zero IntPred.eq; have quotient := ((val a).sub one).udiv (val b); isZero.select zero (quotient.add one)

    arith.ceildivui a, b lowers to a == 0 ? 0 : ((a - 1) udiv b) + 1.

    theorem Veir.Data.LLVM.Int.ceildivsi_lowering (a b : BitVec 8) :
    b = 0 ∨ a = BitVec.intMin 8 ∧ b = -1 ∨ have z := a.sdiv b; val (if a ≠ z * b ∧ a.slt 0 = b.slt 0 then z + 1 else z) = have zero := constant 8 0; have one := constant 8 1; have z := (val a).sdiv (val b); have notExact := (val a).icmp (z.mul (val b)) IntPred.ne; have aNeg := (val a).icmp zero IntPred.slt; have bNeg := (val b).icmp zero IntPred.slt; have signEqual := aNeg.icmp bNeg IntPred.eq; have cond := notExact.and signEqual; cond.select (z.add one) z

    arith.ceildivsi a, b lowers to truncating signed division followed by a one-unit correction when the quotient is inexact and the operands have the same sign.

    theorem Veir.Data.LLVM.Int.floordivsi_lowering (a b : BitVec 8) :
    b = 0 ∨ a = BitVec.intMin 8 ∧ b = -1 ∨ have z := a.sdiv b; val (if a ≠ z * b ∧ a.slt 0 ≠ b.slt 0 then z - 1 else z) = have zero := constant 8 0; have negOne := constant 8 (-1); have z := (val a).sdiv (val b); have notExact := (val a).icmp (z.mul (val b)) IntPred.ne; have aNeg := (val a).icmp zero IntPred.slt; have bNeg := (val b).icmp zero IntPred.slt; have signOpposite := aNeg.icmp bNeg IntPred.ne; have cond := notExact.and signOpposite; cond.select (z.add negOne) z

    arith.floordivsi a, b lowers to truncating signed division followed by a negative one-unit correction when the quotient is inexact and the operands have opposite signs.

    theorem Veir.Data.LLVM.Int.addui_extended_lowering (a b : Int 8) :
    (a.add b, a.uaddOverflowFlag b) = have sum := a.add b; (sum, sum.icmp a IntPred.ult)

    The two results of arith.addui_extended are reproduced by an unflagged llvm.add and llvm.icmp ult.

    theorem Veir.Data.LLVM.Int.subui_extended_lowering (a b : Int 8) :
    (a.sub b, a.usubOverflowFlag b) = (a.sub b, a.icmp b IntPred.ult)

    The two results of arith.subui_extended are reproduced by an unflagged llvm.sub and llvm.icmp ult on the operands: an unsigned subtraction borrows exactly when a <u b.

    theorem Veir.Data.LLVM.Int.mulsi_extended_lowering (a b : Int 8) :
    (a.mul b, a.smulHigh b) = have aExt := a.sext 16 mulsi_extended_lowering._proof_2; have bExt := b.sext 16 mulsi_extended_lowering._proof_2; have wide := aExt.mul bExt; have shiftAmount := constant 16 8; have highWide := wide.lshr shiftAmount; (wide.trunc 8 false false mulsi_extended_lowering._proof_4, highWide.trunc 8 false false mulsi_extended_lowering._proof_4)

    Both results of arith.mulsi_extended are reproduced by sign-extending to twice the width and multiplying once: the low half is that product truncated, and the high half is it shifted right by the original width and truncated.
