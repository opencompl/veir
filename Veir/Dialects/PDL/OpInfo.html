                def Veir.PDL.hasSideEffects (op : PDL) (_props : op.propertiesOf) :
                Bool

                MLIR marks only pdl.range, pdl.result and pdl.results Pure. The rest describe or perform rewrite actions, so treating them as side-effect free lets dead-code elimination delete a pattern body.
