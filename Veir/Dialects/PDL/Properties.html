    structure Veir.PDLAttributeProperties :
    Type

    Properties of the pdl.attribute operation.

    value is the optional constant value the attribute is constrained to. It is absent when the attribute is unconstrained or only constrained by the valueType operand, so it is modelled as an Option and omitted again when printing.
